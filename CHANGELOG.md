### Added
- Hermes-independent routing core (`discord_personas/routing.py`): config
  parsing, persona resolution, loop prevention, outbound persona routing.
- Scoped lock manager with graceful per-persona degradation
  (`discord_personas/locks.py`).
- `DiscordPersonasAdapter` skeleton + `register()` entry point
  (`discord_personas/adapter.py`), with guarded Hermes/`discord.py` imports.
- Persona-namespaced chat-id codec so persona round-trips through Hermes
  session keys (one brain, per-persona sessions).
- Test suite (25 tests) covering the core; runs without Hermes or `discord.py`.
- Release tooling (release-please + git-cliff), CI, and contributor docs.
